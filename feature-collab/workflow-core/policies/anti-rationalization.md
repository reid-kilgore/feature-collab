# Anti-Rationalization

Common failure patterns to pre-debunk:

- "I can just inspect this quickly myself."
- "This phase is obvious, so I can skip it."
- "Tests should be green by now."
- "This adjacent cleanup is basically part of the task."
- "The next session can infer this from the code."
- "The feature is too simple to need demo proof."

Portable rule: if a shortcut weakens evidence, scope discipline, or resumability, reject it.
