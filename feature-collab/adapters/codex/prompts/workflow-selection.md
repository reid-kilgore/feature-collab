# Workflow Selection

Choose a workflow using the portable definitions:

- `spike` when the user does not yet know what to build
- `bugfix` when something that used to work is broken
- `enhance` for a small, local behavior change
- `feature-collab` for multi-component or high-change work
- `handoff` to persist the current session
- `pickup` to resume from artifacts

When in doubt, bias toward the smaller workflow until scope evidence justifies escalation.
